# Roadora v6.7.2.5 — compacte Stops-opruiming

Basisversie: **v6.7.2.4**

Plaats `index.html` over het bestaande bestand met behoud van de mapstructuur.

Deze update verwijdert uitsluitend het grote uitlegblok bovenaan de Stops-tab:
- “Stops en overnachten”;
- de lange uitlegtekst;
- “Resultaten op jouw keuze”.

De categorieën en zoekfuncties beginnen daardoor direct bovenaan. Route-, kaart-, zoek-, opslag- en scrolllogica zijn niet gewijzigd.
